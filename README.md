# IgroCeh API

Бэкенд игрового конкурса для Discord-серверов.

Стек: ASP.NET Core 8, FastEndpoints, EF Core 8, MySQL.

## Как обновить NPSSO

Трофеи PSN сайт читает через служебный аккаунт PlayStation Network. Он входит по NPSSO, cookie этого аккаунта. Обновлять NPSSO нужно, когда страницы конструктора и заявок пишут администратору, что PSN не пускает служебный аккаунт или что NPSSO заканчивается.

1. Войдите служебным аккаунтом на <https://www.playstation.com>.
2. В той же вкладке откройте <https://ca.account.sony.com/api/v1/ssocookie>. В ответе будут `npsso` и `expires_in`, срок действия в секундах.
3. Обновите настройки API в `appsettings` или в переменных окружения (`PsnApiOptions__Npsso`, `PsnApiOptions__NpssoExpiresAt`):

   ```json
   "PsnApiOptions": {
     "Npsso": "значение npsso из шага 2",
     "NpssoExpiresAt": "2027-01-04"
   }
   ```

   `NpssoExpiresAt` — день, когда NPSSO закончится, в формате `гггг-ММ-дд`. Посчитать его из `expires_in` можно так (PowerShell):

   ```powershell
   (Get-Date).AddSeconds(5058589).ToString('yyyy-MM-dd')
   ```
4. Перезапустите API.
5. Откройте конструктор глобального события: предупреждения быть не должно. То же показывает `GET /api/getPsnStatus` для администратора.

`NpssoExpiresAt` необязателен и отвечает только за предупреждение за 7 дней до конца срока, в логе и на страницах администратора. На вход и запросы к PSN он не влияет:

- дата не указана или записана иначе — о конце срока сайт не предупредит;
- дата устарела — будет предупреждение, хотя всё работает. Поменяйте дату в настройках.

Предупреждение о том, что PSN не пускает служебный аккаунт, от даты не зависит. Но пока живы токены, отказ может быть не виден до 10 дней.

**NPSSO — это полный доступ к аккаунту.** Не коммитьте его в репозиторий, не пересылайте и никогда не просите NPSSO у игроков. Привязка PSN у игроков работает через код в поле «Обо мне».
