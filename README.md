# IgroCeh API

Бэкенд игрового конкурса для Discord-серверов.

Стек: ASP.NET Core 8, FastEndpoints, EF Core 8, MySQL.

## Как обновить NPSSO

Трофеи PSN сайт читает через служебный аккаунт PlayStation Network. Он входит по NPSSO, cookie этого аккаунта. Обновлять NPSSO нужно, когда страницы конструктора и заявок пишут администратору, что PSN не пускает служебный аккаунт или что NPSSO заканчивается.

1. Войдите служебным аккаунтом на <https://www.playstation.com>.
2. В той же вкладке откройте <https://ca.account.sony.com/api/v1/ssocookie> и скопируйте значение `npsso`.
3. Обновите настройки API в `appsettings` или в переменной окружения `PsnApiOptions__Npsso`:

   ```json
   "PsnApiOptions": {
     "Npsso": "значение npsso из шага 2"
   }
   ```
4. Перезапустите API.
5. Откройте конструктор глобального события: предупреждения быть не должно. То же показывает `GET /api/getPsnStatus` для администратора.

Срок вводить не нужно. Когда администратор открывает эти страницы, сервер сам спрашивает у PSN, сколько NPSSO ещё действует, но не чаще раза в 6 часов. Предупреждение появляется за 7 дней до конца срока, в логе и на страницах администратора. Если PSN не ответит на этот вопрос, предупреждения просто не будет, а привязка и проверка трофеев от него не зависят.

Без открытия этих страниц сервер срок не спрашивает, поэтому и в логе предупреждения о сроке не появится.

**NPSSO — это полный доступ к аккаунту.** Не коммитьте его в репозиторий, не пересылайте и никогда не просите NPSSO у игроков. Привязка PSN у игроков работает через код в поле «О себе».
